# Student Management System

A console-based Java application developed to manage student records efficiently using Object-Oriented Programming concepts. This project demonstrates CRUD operations, modular class design, encapsulation, and structured data handling using Core Java.

## Features
- Add Student Records
- View Student Details
- Update Existing Records
- Delete Student Records
- Menu-driven Console Interface

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- VS Code

## Concepts Practiced
- Encapsulation
- Classes & Objects
- Arrays / Collections
- Conditional Statements & Loops
- CRUD Operations
